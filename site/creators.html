Sharing the Savant beta

Thank you for sharing Savant. This page has your link and a short, accurate description you can paste. Please use it as written, so what people hear matches what they will find.

Your beta link

Add your code to the end of the link. Everyone who opens it and applies is counted under your code. Only the code is kept, never anything about what they did on other sites.

/beta?ref=YOURCODE

Example: if your code is maya, the link is /beta?ref=maya. Ask the founder for your code.

What to say about Savant

Savant is a learning app that tunes each part of learning to the person: where they start, what comes next, how each lesson is explained, the examples it uses, and when each skill comes back for review. It is in a small beta now, and approved beta testers use it completely free. Applying takes a few minutes.

Please do not

  • Promise test scores or other results. Savant has no published results yet.
  • Collect other people's emails for them. Everyone applies themselves, and a parent applies for a child under 13.
